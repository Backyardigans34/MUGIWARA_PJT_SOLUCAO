# MUGIWARA_PJT_SOLUCAO
Projeto: Agendamento Fácil (Clínica Médica)

👥 Equipe
Membros: Davi Oliveira, Fernando Azevedo, Victor Gabriel Arruda

📝 O Problema:

  Marcar médico hoje em dia é chato. O telefone da clínica vive ocupado, a gente perde tempo esperando e, às vezes, a secretária anota o horário errado no papel. Além disso, muita gente marca a consulta e esquece de ir, fazendo o médico ficar parado sem atender ninguém.

Resumo do problema:

  Dificuldade de falar com a clínica por telefone.
  Erros em agendamentos feitos manualmente (no papel ou Excel).
  Médicos perdendo tempo com pacientes que faltam sem avisar.

💡 Nossa Solução:

  Vamos criar um site onde o paciente entra, vê os horários que o médico tem livre e reserva o seu na hora. Tudo automático!
    Como o sistema ajuda:
      Site 24h: O paciente pode marcar a consulta até de madrugada se quiser.
      Confirmação Visual: O paciente vê na tela que o horário está reservado para ele.
      Organização: A clínica tem uma lista pronta de quem vai ser atendido no dia, sem bagunça de papéis.

🛠️ Tecnologias (Linguagem Simples):

  Escolhemos tecnologias que funcionam muito bem juntas e são fáceis de instalar:
    PHP: É o "motor" do site. Ele vai receber o pedido do paciente e salvar no sistema.
    HTML & CSS: O HTML é a estrutura (textos e botões) e o CSS é o que deixa o site bonito, com cores e organizado.
    MySQL: É onde vamos guardar as informações dos pacientes e os horários das consultas.
